# Payroll System — Frontend

React frontend for the payroll system. Staff can manage employees, record work hours and view payroll results through the [backend_payroll](https://github.com/Abdullahahmad666/backend_payroll) API.

**Live:** https://frontend-payroll.vercel.app

## Tech stack
React · React Router · Axios · Bootstrap · Create React App · Vercel

## Run locally
```bash
git clone https://github.com/Abdullahahmad666/frontend_payroll.git
cd frontend_payroll
npm install
npm start          # http://localhost:3000
```
Set the API base URL in `src/App.js` (or a `REACT_APP_API_URL` environment variable) to your backend.
